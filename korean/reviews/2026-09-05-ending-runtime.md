# 엔딩 화면 런타임 번역 검수

## 화면 표시 경로

- `GameApplication::buildWinGameCertificate()`가 본문·캐릭터 소개·점수·플레이 시간을 생성한다.
- `WinGameScreen::drawScreen()`이 해당 인증서 내용을 실제 엔딩 화면에 표시한다.
- 본문은 원래 영어를 먼저 줄바꿈하고 각 줄을 번역하려 했으므로, 기존의 전체 문장 번역과 일치하지 않았다.
  전체 본문을 먼저 번역하고 UTF-8 글자 경계를 유지하는 공통 줄바꿈 함수를 사용하도록 수정했다.
- 캐릭터의 이름·레벨·직업과 시간 계산은 원본 로직에 그대로 두고 최종 표시에서만 번역한다.

## 검수한 문구

| 원문 형식 | 한국어 표시 |
| --- | --- |
| Congratulations! | 축하합니다! |
| Alice the Level 50 Master Archer | Alice - 레벨 50 명궁 |
| 미나 the Level 1 Adventurer | 미나 - 레벨 1 모험가 |
| Your score: 12345 | 점수: 12345 |
| Total Time: 2 Years, 1 Month, 27 Days | 총 시간: 2년, 1개월, 27일 |

본문은 기존에 검수된 번역을 재사용한다. 플레이어가 만든 이름은 번역하거나 잘라내지 않는다.
시간은 단수와 복수를 모두 처리하며, `Years`를 `Year`보다 먼저 치환해 영어 `s`가 남지 않도록 한다.

## 회귀 검사

`tests/KoreanTextLayoutTests.cpp`에서 다음을 확인한다.

- 영문·한글 이름 및 공백을 포함한 직업명
- 이름에 `the Level`이 포함된 경우와 잘못된 레벨 형식
- 0·1·여러 해/개월/일과 점수
- 전체 본문 번역 후 UTF-8 줄바꿈, 본문 복원, 줄 폭 및 시간 표시 영역과의 간격

전체 게임 번역 완료를 뜻하지 않는다. 이미지 속 영어와 개발 로그·로직 키는 이번 수정 대상이 아니다.
