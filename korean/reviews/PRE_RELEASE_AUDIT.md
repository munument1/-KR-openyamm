# 최종 빌드 전 한국어 누락 검수

2026-09-05 사용자 요청에 따라, 새 릴리즈를 반복하는 대신 남은 누락을 먼저 묶어 점검한다.
이미 시작한 r4 빌드는 이 검수 완료를 증명하지 않는다. 아래 미완료 항목을 확인한 뒤 최종 빌드로 넘어간다.
작업 중인 누락 수정은 로컬에서 검증하고, 자동 smoke 빌드를 유발하는 푸시는 검수 묶음이 준비될 때 수행한다.

## 완료 기준

- 고정 제목, 데이터로 치환되는 값, 동적으로 합치는 문장·목록을 구분한다.
- 영어가 검색된다는 이유만으로 로직 키·파일명·로그·사용자 지정 이름을 번역하지 않는다.
- 실제 표시 경로가 확인된 누락을 수정하고, 번역 후 줄바꿈·길이·글꼴과 데이터 보존을 검증한다.
- 카탈로그 100%, 번역 정의 존재, 소스 검수, 실제 화면 확인을 서로 다른 증거로 기록한다.
- 이미지에 새겨진 영어는 제외한다.
- 아래 화면군에 미분류 후보와 확인된 미수정 누락이 남아 있으면 누락 검수 완료로 안내하지 않는다.

## 1차 정적 기준선

- `assets_dev/engine/ui`의 따옴표로 지정된 `text.value` 207개를 수집했다.
- 그중 고정 영어 항목은 71곳, 서로 다른 문구는 51종이다. 모두 현재 표시 번역 소스에 대응 정의가 있다.
- 동적 치환이 포함된 항목은 110곳이다. 이 값들의 생성·결합·줄바꿈 경로는 별도로 확인해야 한다.
- 이 수치는 UI 레이아웃의 해당 필드 범위만 뜻한다. 게임 전체 문구 수나 실제 화면 검수율이 아니다.
- 기존 휴리스틱 감사는 코드 490개 파일에서 미검수 후보 3,246곳을 반환했다.
  여기에 파서·디버그·이미 번역되는 문장 조각이 다수 섞여 있으므로 번역 누락 개수로 사용하지 않는다.
  반대로 한 단어 항목이나 동적 결합 누락을 놓치므로 이 도구의 결과만으로 완료 판정하지 않는다.

## 이번 묶음의 확인된 수정

### 몬스터 효과 목록

`GameplayPartyOverlayRenderer.cpp`에서 활성 효과를 `joinNonEmptyTexts()`로 먼저 합치면
`Haste, Shield`는 단일 효과의 정확 일치 번역을 거치지 못한다.
전용 `actorEffectsText()`에서 각 효과를 번역한 후 합치도록 변경했다.
빈 목록, 22개 효과, 시전 중 표시, 이미 한국어인 값, 쉼표가 들어간 사용자 정의 효과 보존을 검사했다.
`Stoneskin`은 주문 카탈로그 `engine:spells.txt:38:Name` 및 기존 시전 표시의 `돌가죽`으로 맞췄다.

로컬 C++ 검사: 23개 테스트, 8,253개 단언 통과. 이 수정의 실제 실행 화면 검수는 아직 하지 않았다.

### 기술명과 숙련도 결합

`GameplayHudOverlaySupport.cpp`의 정규 기술 목록과 추가 기술 목록은 영어 기술명에 `Expert/Master/Grand`를
붙인 후 표시하여 정확 일치 번역에서 빠졌다. 기술명과 숙련도를 분리해 번역한 후 합치도록 수정했다.
전역 기술·숙련 데이터와 직업명 `Master = 달인`은 바꾸지 않는다.
그랜드마스터의 좁은 목록용 표기는 기존 축약 방식에 맞춰 `그랜드`로 표시한다.
`tests/KoreanSkillDataTests.cpp`는 실제 `SkillData.cpp`에서 기술 40종을 불러와 5단계 숙련과 조합한
200개 표시 문자열에 영어가 남지 않고, 좁은 이름 칸 148 논리 픽셀 안에 들어가는지 검사한다.

### 몬스터 공격 유형 및 주문 숙련

활성 `monster_data.txt`의 두 공격 유형 열에 있는 비어 있지 않은 값은
`0, Air, Dark, Earth, Ener, Fire, Light, Phys, Pois, Water`다.
`Phys/Pois/Ener`는 화면용 함수에서만 `물리/독/에너지`로 변환한다.
숫자 0은 기존 행 생략 표식으로 유지한다. 알 수 없는 모드의 유형명은 보존한다.
`Pois`는 거대 거미 계열의 두 번째 공격에 쓰이는 원본 표기이며, 이 작업은 공격 판정 파서를 수정하지 않는다.
주문 옆의 `N/E/M/GM`도 화면용 숙련 표기로 바꿨다. 주문 이름은 기존 주문 테이블의 한국어 ShortName을 사용한다.

### 아이템 이름·특수 효과·상세 문장

- 일반·특수 마법 부여 표시 접두/접미 98개는 카탈로그에 들어 있다.
- `ItemEnchantTables.cpp`는 한국어 표시 열 20·21을 사용하고 판정 종류·접두/접미 배치는 원본 열에서 계산한다.
- `ItemEnchantRuntime.cpp`의 이름·능력치·특수 효과 설명은 이 로더의 표시 값을 사용한다.
- 공격·사격·피해·충전·방어력·기간·특수 효과·세트 상태의 복합 문장을 회귀 테스트에 추가했다.
- 기본 에셋의 조사 범위에서 활성 `item_sets` 기여는 발견하지 못했다. 사용자 정의 세트의 식별자는 번역하지 않는다.
- 주사위 수식 `2D6+2`와 사용자 지정 이름은 미번역 영어 문장으로 분류하지 않는다.

## 현재 로컬 검증 결과

이 수치는 화면 전체 검수 완료를 뜻하지 않는다. 수정된 기술·몬스터 정보 화면의 실제 실행 검증은 남아 있다.
등록 기술 전수 검사는 `tests/KoreanSkillDataTests.cpp`와 실제 `game/party/SkillData.cpp`를 함께 컴파일한다.
새 릴리즈 태그·푸시는 수행하지 않았다.
