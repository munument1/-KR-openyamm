# 저장·불러오기 날짜와 시각 검수

## 확인한 표시 경로

- 메인 메뉴 `LoadGameScreen.cpp`: `Monday 09:00AM`, `1 January 1168`.
- 게임 중 `GameplaySaveLoadUiSupport.cpp`: `Mon 9:00 AM`, `Jan 1, 1168`.
- 기존 공통 번역은 공백이 있는 AM/PM만 처리해 약식 요일이 영어로 남았고,
  메인 메뉴 시각 및 게임 중 약식 날짜 형식은 번역하지 못했다.

## 수정과 검증

최종 표시 단계에서 두 형식을 모두 인식해 한국어 요일·오전/오후·년월일로 표시한다.
시간 계산, 저장 파일 형식과 이름은 변경하지 않는다. 숫자와 구분자를 검증해
일반 문장이나 손상된 값은 날짜로 잘못 번역하지 않는다.

`KoreanCalendarTextTests.cpp`는 일곱 요일, 열두 달, 정오·자정, 기존 시각 형식,
잘못된 값과 일반 문장을 검사한다. 기존 회귀 검사를 포함해 로컬 C++20 테스트
15개 케이스, 7,736개 단언이 통과했다. 플랫폼 빌드 및 실제 화면 검수는 별도이다.
