# r3 공식 패키지 검증 및 전투 상태줄 추가 수정

## 공식 배포본

- 태그: `0.11-korean-r3`, 소스: `489c2b4d1086c375afd2e2880db1f321336763b6`.
- 릴리즈 작업 `33960945112`: Windows ZIP, 서명된 Android arm64 릴리즈 APK, Flatpak 게시 성공.
- 공식 Windows ZIP을 다시 내려받아 게시된 SHA-256과 대조하고 ZIP CRC 검사를 통과했다.
- SHA-256: `0cf8bd86c37f5bb0315b005ae24b1a034ab150ccf455ec042803f29a9613aeb0`.
- 패키지 내부 한국어 `engine.zip`의 파일 30개는 검수한 전체 가져오기 산출물과 바이트 단위로 같다.
- 네 월드 오버레이의 Lua 본문도 같다. 로컬 CRLF와 CI LF 차이만 있으며 원본 파일은 변경하지 않았다.
- 갈무리11 파일 해시와 OFL 포함 여부를 확인했다.

## 실제 실행

- 공식 ZIP에서 추출한 실행 파일로 MM8 캐릭터 생성 화면과 캐릭터 능력치 화면을 확인했다.
- 생성 화면의 한국어 기술명과 능력치 화면의 나이·레벨·경험치·공격·피해·생명력·주문력·방어력 등이 표시된다.
- 갈무리11로 표시되는 해당 문구에서 누락이나 겹침을 발견하지 못했다. 이미지의 영어 버튼은 유지했다.
- 테스트용 추출 폴더의 음량·창 크기·시작 설정만 조정했다. 원본 ZIP과 사용자 설치본은 수정하지 않았다.
- 로컬 증거: `_codex/r3-release/character-creation.png`, `character-stats.png`, `package-verification.json`.

## 새로 확인한 번역 누락

능력치 화면 아래 상태줄에 `Ariel evades damage`가 실제로 표시되었다.
`GameplayCombatController::showHitStatus()`가 동적으로 조립한 문장을 상태줄로 보내는 경로다.
고정 문자열로 직접 호출하는 `setStatusBarEvent("...")` 검색만으로는 이 경로를 검증할 수 없다.

- 회피, 근접 명중, 원거리 명중, 처치, 마비, 기절의 여섯 형식을 최종 표시 치환에 추가했다.
- `이름: 대상 결과 (피해 수치)` 형태로 조사 충돌을 피한다. 이름·피해 값·전투 판정은 보존한다.
- 잘못된 수치·빈 대상·기존 한국어·디버그 로그는 전투 상태 문구로 번역하지 않는 테스트를 추가했다.
- 로컬 C++ QA: 22개 테스트, 8,075개 단언 통과.
- 이 전투 수정과 앞선 키 설정 수정은 r3 이후 소스다. r3에 포함되지 않았다.
- 새 전투 수정의 실제 실행 화면 및 이를 포함한 Windows/Android 빌드 검증은 아직 남아 있다.
