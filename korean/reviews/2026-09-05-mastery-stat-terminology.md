# 숙련도 승급 안내의 능력치 용어

`MasteryTeacherDialog.cpp`에서 체력 단련 마스터의 기본 능력치 조건은
`base Endurance`이며, 능력치 화면의 대응 명칭은 `체력`이다.
기존 안내의 `기본 인내력`을 `기본 체력`으로 수정해 서로 다른 능력치로
오해하지 않게 한다. 조건 수치 50과 실제 승급 판정은 변경하지 않는다.

기술 서비스 회귀 검사에 능력치 단독 명칭과 전체 조건 문구를 추가했다.
기존 검사를 포함해 로컬 테스트 15개 케이스, 7,738개 단언을 통과했다.
이 수정은 r2 태그 이후의 변경이며 r2 패키지에는 포함되지 않는다.
