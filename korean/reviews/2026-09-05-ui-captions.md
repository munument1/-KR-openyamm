# UI 항목명·짧은 문구 검수

기존 런타임 감사 스크립트는 한 단어짜리 문자열과 `HP:` 같은 약어를 내부 키 후보로
제외했다. 따라서 카탈로그 검사가 통과해도 다음 실제 표시 문구는 영어로 남을 수 있었다.

## 확인한 표시 경로

- `assets_dev/engine/ui/gameplay/quick_reference.yml`: 이름·직업·능력치·상태·빠른 주문 항목.
- `character.yml`: 능력치·기술 점수·기술 분류 항목.
- `actor_inspect.yml`: 생명력·방어력·공격·저항 속성 항목.
- `rest.yml`: 날짜의 일·월·년 항목.
- `lloyds_beacon.yml`: 봉화 설치·귀환 버튼의 텍스트.
- `GameplayPartyOverlayRenderer.cpp`의 모험가 여관: `Name:`, `HP:`, `Cond:` 등 조립 문구.
- 같은 렌더러의 아이템 상세: `Type: `와 해석된 아이템 유형.

위 YAML의 `text.value`는 `renderLayoutLabel()`의 최종 번역 단계를 거쳐 표시된다.
이 값은 배경 이미지나 게임 내부의 아이템 분류 키가 아니다. 이미지와 lookup 값은 수정하지 않고
표시 치환만 추가했다. 모험가 이름은 보존하며, 직업·상태·유형 필드만 기존 번역 용어를 적용한다.

짧은 항목명은 검수된 능력치 용어를 따르며 `SP`는 60px 칸에 맞는 `주문력`으로 표시한다.
파티 요약의 모든 항목명이 갈무리11 12px 기준 60px 폭에 들어가는 회귀 검사를 추가했다.
다른 정적 UI 항목명과 모험가 여관·아이템 상세 조립 문구도 전체 문자열로 검사한다.
기존 검사를 포함해 로컬 C++20 테스트 18개 케이스, 7,860개 단언이 통과했다.

이 변경은 r2 태그 이후이며 r2 패키지에는 포함되지 않는다. 실제 실행 검수 및 후속 패키지가 필요하다.
