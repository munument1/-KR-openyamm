# 여러 줄 인사말·대화·두루마리 번역 누락 수정

## 실행 화면에서 확인한 문제

r2 소스 실행 파일과 기존 공식 한국어 오버레이로 스톤과 대화했을 때 다음처럼 나타났다.

- 첫 줄: `다데로스와 이야기해 보셨습니까?`
- 둘째 줄: `What are we to do now?`

원문 `npc_greet.txt`와 MMMerge의 한국어 파일 모두 일부 셀에 따옴표 없는 줄바꿈을 사용한다.
게임의 `NpcDialogTable`은 다음 숫자 ID까지의 행을 하나의 인사말·대화로 합치지만,
기존 카탈로그 생성기는 첫 물리 행만 번역하고 이어지는 영어 행을 남겼다.
한국어 원본의 이어지는 행도 읽지 않아 카탈로그 완료율만으로는 이 누락을 찾을 수 없었다.

## 수정

- 인사말은 런타임과 같은 ID 경계 및 열 이어붙이기 방식으로 원문 문장 전체를 조립한다.
- NPC 본문은 런타임처럼 텍스트 열에 다음 행의 문장을 합친다.
- 한국어 필드 오버레이는 공통 `text_localization.py`에서 전체 문장과 문단을 읽는다.
- 같은 문제를 확인한 직업 설명과 두루마리도 이 공통 판독기를 사용한다.
- 소년의 대회 안내(인사말 332)는 첫 줄뿐 아니라 세 줄 전체를 직접 번역했다.
- 중복 ID/필드와 소속 레코드 없는 번역 행은 조용히 무시하지 않고 오류로 처리한다.
- 따옴표로 감싼 정상적인 여러 줄 셀은 다시 분리하지 않는다. NPC 소유자·ID·열 위치를 보존한다.

## 영향 범위와 검증

한국어 참조 소스: `munument1/-KR-MMMerge`의 `b0c62081c2d0967050f2ae66446b9e54a405b2e0`.
기존 r1 검수 카탈로그와 전체 재생성 결과를 비교했다.

- 기존 카탈로그 24,743개 → 24,802개: 인사말 항목 59개 복구.
- 기존 번역 변경: NPC 본문 1,791개, 인사말 327개, 대화 주제 3개,
  두루마리 7개, 직업 설명 1개. 새 문장을 임의 생성한 것이 아니라 누락된 원본 번역 문단을 복구한 수치다.
- 전체 릴리즈 오버레이 생성 성공: 24,802/24,802, 미번역·검토 필요·자리표시자 불일치 0.
- 여섯 Python 회귀 테스트: 인사말 양쪽 필드, 본문 메타데이터, 따옴표·빈 문단,
  중복/고아 레코드, 카탈로그와 출력 파일 일치, 두루마리·직업 설명의 여러 줄 보존.
- 실제 C++ `TextTable` + `NpcDialogTable`에 생성 파일을 로드해 스톤, 다데로스,
  소년의 전체 문구를 검사했다.
- 독립 검수용 게임에서 스톤의 두 줄 인사말이 모두 한국어로 표시됨을 확인했다.
  기존 사용자 설치본과 저장 파일은 변경하지 않았다.

이 수정은 r2 이후의 변경이며 r2 배포 파일에 포함되지 않는다.
카탈로그 전체 통과는 모든 게임 화면의 번역 완료를 의미하지 않는다.
