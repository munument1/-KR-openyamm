# 행동 버튼 문구 검수

## 실제 표시 경로

`GameplayInteractionController`가 만든 `GameplayContextAction::label`은
`GameplayHudRenderer::renderMobileContextAction()`에서 두 줄 버튼 문구로 표시된다.
아이템을 버리는 버튼과 선택적인 행동 팝업에서 사용하는 경로이다.

기존 코드는 원문을 먼저 줄로 나눈 뒤 렌더러에서 번역했다. 말줄임표 처리에서는
`pop_back()`으로 UTF-8의 마지막 바이트를 제거했고, 두 번째 줄 생성 시 현재 단어를
남은 문자열과 중복해서 합치는 분기도 있었다.

## 수정

- 완성된 버튼 문구를 먼저 번역한다. `Open Chest (이름)`도 전체 형식으로 번역한다.
- 공통 `Utf8LabelLayout.h`에서 글자 경계를 유지하며 최대 두 줄로 배치한다.
- 양쪽이 들어가는 경우 기존처럼 단어 사이에서 균형 있게 나눈다.
- 공백 없는 긴 한글도 글자 단위로 나누며, 넘치는 마지막 줄만 말줄임 처리한다.
- 말줄임표 자체가 칸보다 길면 점 개수도 줄여 표시 폭을 넘지 않는다.
- 게임 행동 종류·이벤트 메타데이터·이름 lookup은 변경하지 않는다.

## 검증

`tests/Utf8LabelLayoutTests.cpp`는 단어 중복, 한글 경계, 공백 없는 이름, 좁은 칸,
0.5/1/2/3배 표시 배율 및 이름이 붙은 상자 열기 문구를 검사한다.
기존 회귀 검사를 합쳐 로컬 C++20 검사 12개 케이스, 7,652개 단언이 통과했다.
실제 플랫폼 빌드와 실행 화면 검수는 별도 확인이 필요하다.
