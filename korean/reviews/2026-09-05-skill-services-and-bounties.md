# 기술 서비스·현상금 런타임 검수

## 표시 경로와 문제

- `HouseInteraction.cpp`의 기술 구매 선택지·습득 결과·습득 불가 안내는 `displaySkillName()`으로
  생성한 영문 기술명을 문장에 넣는다. 기존 최종 표시 치환은 문장만 번역하고 기술명을 그대로 남겼다.
- `MasteryTeacherDialog.cpp`도 숙련 승급 안내 및 결과에 같은 기술명을 넣는다.
  직업 제한 문구의 `class.`와 선택 가능한 여러 승급 직업명의 `or`도 남았다.
- `BountyHuntRuntime.cpp`는 NPC 번역 데이터가 없는 경우 몬스터 이름과 금액으로 안내문을 생성한다.
  이 fallback의 `for ... gold` 또는 `gold`는 기존 치환 후에도 영어였다.
- `localizedGameplayHudText()`는 런타임 치환 결과를 즉시 반환하므로 남은 영어가 재번역되지 않는다.

## 수정 원칙

- 게임 로직·직업/기술 lookup key·금액 계산은 변경하지 않는다.
- 문장 안에서 기술명으로 확인된 필드에만 기존의 정확 일치 번역을 재사용한다.
- 플레이어/몬스터 이름은 보존한다. 이름이 `Sword`라고 해도 `검`으로 번역하지 않는다.
- 알려지지 않은 모드 기술명은 원문을 유지하며, 문장 전체에 대한 재귀 치환은 하지 않는다.
- 현상금은 `이번 달 현상금 대상: 이름 (보상: 금액골드)` 형식으로 표시한다.
- 승급 직업 목록은 각 직업을 번역하고 마지막 선택 연결어를 `또는`으로 표시한다.

## 검증

`tests/KoreanServiceTextTests.cpp`는 8개 기술의 서비스 문장, 한글·영문 플레이어 이름,
이미 번역된 기술명, 미등록 기술명, 단일/복수 승급 직업, 현상금 대상 이름과 금액 보존을 검사한다.
전체 게임 번역 완료를 주장하는 검사는 아니다.
