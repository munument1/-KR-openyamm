# 파티 정보의 직업·평판 검수

`displayClassName()`은 내부 직업 ID를 공백이 있는 영어 표시명으로 바꾸는 공용 함수이다.
이를 한국어 함수로 바꾸면 로직 키를 소비하는 다른 경로에 영향을 줄 수 있다.
따라서 파티 요약, 캐릭터창의 직업 필드, 캐릭터 상세 팝업 제목을 만들 때에만
기존 `KoreanRuntimeText::className()`을 적용한다.

파티 요약 하단의 `Reputation:`과 다섯 단계의 평판 값, `Fame: 숫자`도
실제 렌더러에서 표시되는 것을 확인하고 번역했다. 평판 계산과 색상 판정은 변경하지 않는다.

직업 `Master`의 `달인` 번역이 기술 숙련도의 `마스터`와 혼동되지 않게
직업 전용 변환을 사용한다. 사용자 정의 직업과 이미 번역된 직업명은 유지한다.
회귀 검사는 총 19개 케이스, 7,873개 단언을 통과했다.

이 변경은 r2 태그 이후이며 r2 패키지에는 포함되지 않는다. 네이티브 빌드와 실행 검수는 별도이다.
