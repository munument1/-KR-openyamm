# 키 설정 화면 문구 검수

## 확인 및 수정

- `KeyboardBindings.cpp`의 동작 설명 29개가 키 설정 화면에 영어로 전달되는 경로를 확인했다.
- 화면 표시 전용 함수로 이동·시전·캐릭터 전환·파티 요약 등의 설명을 한국어로 변환했다.
- 미지정 입력과 마우스 버튼 설명을 번역했다. `Q`, `Page Down` 등 실제 키에 적힌 이름은 유지한다.
- 입력 처리, 동작 식별자, 저장된 키 설정 값은 수정하지 않았다.
- 조작·비디오 설정의 이미지 기반 버튼과 로딩 이미지는 요청에 따라 변경하지 않았다.

## 검증 범위

- 29개 동작명 전체의 번역 여부와 좁은 쪽 설명 열의 가용 폭 104 논리 픽셀을 단위 테스트한다.
- 알 수 없는 동작명, 기존 한국어, 실제 키 이름을 보존하는 테스트를 추가했다.
- 이 변경은 `0.11-korean-r3` 태그 이후의 소스 수정이다. r3 패키지에 포함되었다고 안내하지 않는다.
- 키 설정 화면의 실제 실행 검수와 이 변경을 포함한 전체 빌드는 아직 수행하지 않았다.
