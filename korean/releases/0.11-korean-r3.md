# OpenYAMM 0.11-korean-r3

갈무리11 글꼴을 사용하며, UI 항목명과 여러 줄 대화의 번역 누락을 수정한 한국어판입니다.

- 여러 줄 NPC 인사말·대화에서 첫 줄만 번역되던 가져오기 오류를 수정했습니다.
- 누락된 인사말 항목 59개와 NPC 본문·두루마리·직업 설명의 뒷문장을 복구했습니다.
- 스톤의 두 줄 인사말이 모두 한국어로 표시되는 것을 Windows 실행 화면에서 확인했습니다.
- 파티 요약, 캐릭터 정보, 평판·명성, 여관과 아이템 상세의 항목명을 한국어로 표시합니다.
- 파티 요약·캐릭터 상세의 직업명을 번역하고 체력 단련 승급 조건의 용어를 통일했습니다.
- r1/r2의 캐릭터 생성 기술명 줄바꿈, 한글 행동 버튼, 엔딩·서비스 안내·저장 날짜 수정을 포함합니다.

이미지에 새겨진 영어 제목·버튼은 요청에 따라 원본을 유지합니다.
전체 카탈로그 24,802개 검사는 통과했지만, 모든 게임 장면을 직접 플레이해 검수했다는 뜻은 아닙니다.
키 설정 동작명과 일부 전투 상태줄의 영어는 r3에 남아 있으며, 후속 소스에서 수정 중입니다.

## 설치 및 검증

Windows는 ZIP을 새 폴더에 풀고 `openyamm.exe`를 실행하세요.
Android arm64는 서명된 릴리즈 APK이며 버전 코드는 1103입니다.
업데이트 전에 기존 저장 파일을 백업해 주세요. 각 파일의 `.sha256`으로 다운로드 무결성을 확인할 수 있습니다.

공식 Windows ZIP의 체크섬·내부 한국어 데이터·폰트와 라이선스를 확인했고,
해당 실행 파일의 캐릭터 생성·능력치 화면에서 한국어 표시를 검증했습니다.
