# OpenYAMM 0.11-korean-r2

갈무리11을 유지하면서 실제 화면에서 남아 있던 영어와 한글 배치 오류를 추가 수정한 한국어판입니다.

- 기술 습득·숙련도 승급 안내의 기술명과 전직 조건을 한국어로 표시합니다.
- 현상금 대사의 보상 안내와 엔딩 인증서의 직업·기간 문구를 수정했습니다.
- 긴 행동 버튼은 번역 후 줄을 나누며, 한글 깨짐과 단어 중복을 방지합니다.
- 저장·불러오기 화면의 요일, 오전/오후, 날짜를 한국어로 표시합니다.
- r1의 갈무리11 글꼴과 캐릭터 생성 기술명 줄바꿈 수정을 포함합니다.

이미지에 새겨진 영어 제목과 장식 문구는 원본을 유지합니다. 게임 전체 화면의 번역 완료를
보증하는 버전은 아니며, 미확인 화면의 잔여 문구 검수는 계속 진행합니다.

알려진 잔여 문제: 일부 UI 항목명과 여러 줄 NPC 대화의 뒷문장이 영어로 남을 수 있습니다.
후속 소스에서 수정 중이며, 이 r2 배포 파일에는 해당 후속 수정이 포함되지 않습니다.

## 설치

Windows는 ZIP을 새 폴더에 풀고 `openyamm.exe`를 실행합니다.
Android는 arm64 릴리즈 APK이며 버전 코드는 1102입니다.
기존 저장 파일은 업데이트 전에 백업해 주세요. 각 배포 파일의 `.sha256`으로 무결성을 확인할 수 있습니다.

갈무리11 2.40.4와 SIL Open Font License가 패키지에 포함됩니다.
