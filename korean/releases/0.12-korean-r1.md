# OpenYAMM 0.12-korean-r1

OpenYAMM 0.12 기반으로 한국어판을 이식한 첫 릴리즈입니다.

- OpenYAMM 0.12의 MM6~8 게임플레이 수정, TTF 폰트 지원, 잔디 셰이더 및 업스케일 에셋 지원을 반영했습니다.
- 기존 한국어 런타임 표시, UI 보정, 대화·건물·상호작용 번역 경로, 영상 자막 및 갈무리11 폰트 처리를 0.12 코드베이스에 재이식했습니다.
- 0.12 소스 기준으로 전체 번역 카탈로그를 다시 생성하고 검증했습니다.
- 최종 카탈로그는 25,324 / 25,324 번역 완료이며, untranslated 0, needs_review 0, REVIEW_QUEUE 0입니다.
- MM6 365/365, MM7 135/135, MM8 181/181, MMMerge 3/3의 지도 런타임 문자열이 번역 상태로 생성됩니다.
- 한국어 런타임 경로 검사, 표시 문자열 감사, 텍스트 레이아웃·스킬·주문·달력 회귀 테스트와 번역 importer 테스트를 통과했습니다.
- 한국어 overlay 패키징 및 fallback TTF 폰트 포함 여부를 검증했습니다.

0.11-korean-r4까지의 한국어 번역 및 런타임 수정 사항을 포함합니다.

## 설치

Windows ZIP은 새 폴더에 풀고 `openyamm.exe`를 실행하세요.
기존 설치를 갱신하는 경우 저장 파일을 먼저 백업하는 것을 권장합니다.

갈무리11 2.40.4와 SIL Open Font License를 포함합니다.
