# OpenYAMM 0.11-korean-r4

갈무리11을 사용하는 한국어판의 키 설정·전투 안내 수정판입니다.

- 키 설정의 이동·주문 시전·캐릭터 전환·파티 요약 등 동작 설명 29개를 번역했습니다.
- 클래식 모드의 좌우 회전과 현대식 모드의 좌우 이동을 구분해 표시합니다.
- 미지정 입력과 마우스 버튼 설명을 번역했습니다. 실제 키에 적힌 `Q`, `Page Down` 등은 유지합니다.
- 전투 상태줄의 피해 회피, 근접·원거리 명중, 처치, 마비, 기절 안내를 번역했습니다.
- 캐릭터 이름·피해 수치·조작 키·전투 판정은 유지합니다.
- r3의 여러 줄 NPC 대화 복구, 캐릭터 정보·직업명·평판 표시 수정을 모두 포함합니다.

이미지에 새겨진 영어 제목과 버튼은 요청에 따라 원본을 유지합니다.
모든 게임 장면의 번역이 완벽하다고 보장하는 릴리즈는 아니며, 남은 실제 표시 문구를 계속 검수하고 있습니다.

## 설치

Windows ZIP은 새 폴더에 풀고 `openyamm.exe`를 실행하세요.
Android arm64 APK는 서명된 릴리즈 빌드이며 버전 코드는 1104입니다.
업데이트 전 저장 파일을 백업하고, 함께 제공하는 `.sha256`으로 다운로드 무결성을 확인해 주세요.
